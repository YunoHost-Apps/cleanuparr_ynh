# Cleanuparr for YunoHost

Advanced download manager for the Servarr ecosystem.

Upstream project: <https://github.com/Cleanuparr/Cleanuparr>

This repository contains the YunoHost package. Development changes should target the `testing` branch before being promoted to `main`.

To install the testing package on a YunoHost server:

```bash
sudo yunohost app install https://github.com/YunoHost-Apps/cleanuparr_ynh/tree/testing
```
