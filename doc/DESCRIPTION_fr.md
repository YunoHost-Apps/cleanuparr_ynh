Cleanuparr est un gestionnaire avancé de téléchargements pour l'écosystème Servarr. Il se connecte à Sonarr, Radarr, Lidarr, Readarr et aux autres applications *arr prises en charge, ainsi qu'aux clients de téléchargement courants, afin de nettoyer les téléchargements bloqués, échoués ou orphelins.

L'application fournit sa propre interface web et son propre système d'authentification. Après l'installation, configurez les clients de téléchargement et les applications *arr depuis l'interface Cleanuparr.
